# Data Jobs Dashboard – Power BI

This is an interactive Power BI dashboard I built to explore data-related job postings. It shows things like total job count, salary trends, top-paying roles, and more.

You can filter by job title and use the drill-through feature to see detailed information for specific roles (for example Senior Data Scientist or Senior Data Analyst).

### Tools Used
- Power BI Desktop
- Power Query
- Basic DAX

### What’s included

**Main Page**
- Total number of jobs
- Median yearly and hourly salary
- Job posting trend in 2024
- Top paying data jobs
- Hourly vs Yearly salary comparison
- Summary statistics table

**Drill-through Page**
- Median salary
- Work from home percentage
- Degree requirement
- Health insurance
- Global distribution map
- Top platforms (LinkedIn, Indeed, etc.)
- Job type breakdown (Full-time, Contract, etc.)

### Some Insights
- Senior Data Scientist and Machine Learning Engineer are among the highest paying roles
- Most jobs are full-time positions
- LinkedIn is one of the main platforms for data job postings
- There was a noticeable decline in job postings during the second half of 2024

### How to view the dashboard
1. Download the `.pbix` file
2. Open it in Power BI Desktop
3. Use the filters and drill-through buttons to explore different job titles
